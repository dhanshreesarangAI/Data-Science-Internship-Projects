# Project 2 — Titanic Survival Prediction 🚢

## Problem Statement
Can we predict who survived the Titanic disaster 
based on passenger features?

## Dataset
- Name: Titanic Dataset
- Source: Kaggle
- Rows: 891 passengers
- Columns: 12

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Models & Results
| Model | Accuracy | ROC-AUC |
|-------|----------|---------|
| Logistic Regression | 80.4% | 0.882 |
| Decision Tree | 79.9% | 0.856 |

## Key Findings
- Females survived 74% vs males only 19%
- Class 1 passengers survived 63%
- Children had higher survival rate
- Gender and Class are top predictors

## Conclusion
Logistic Regression performed best with 80.4% 
accuracy and 0.882 ROC-AUC score
