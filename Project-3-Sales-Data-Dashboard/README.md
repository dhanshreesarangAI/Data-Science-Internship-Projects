# Project 3 — Sales Data Dashboard 📊

## Problem Statement
How can we visualize sales data to help decision-makers 
understand business performance?

## Dataset
- Name: Superstore Sales Dataset
- Source: Kaggle
- Rows: 9800 orders
- Columns: 18

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Steps Performed
1. Data Loading
2. Data Cleaning
3. KPI Calculation
4. Sales by Category Chart
5. Sales by Region Chart
6. Monthly Sales Trend Chart
7. Top Sub-Categories Chart
8. Sales by Segment Chart
9. Sales by Ship Mode Chart
10. Business Insights

## Key KPIs
- Total Sales    : $2.26 Million
- Total Orders   : 5009
- Total Customers: 793
- Avg Order Value: $230

## Key Findings
- Technology is best selling category
- West region has highest sales
- Consumer segment contributes most
- Sales peak in November-December
- Standard Class is most used ship mode

## Conclusion
This dashboard provides complete visibility into 
business performance helping decision makers 
identify top performing categories, regions 
and customer segments
